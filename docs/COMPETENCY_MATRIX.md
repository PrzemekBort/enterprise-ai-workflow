# Competency Matrix v2

## Skala
- **0** — nie wiem, co to jest
- **1** — kojarzę pojęcie
- **2** — rozumiem z pomocą
- **3** — potrafię użyć samodzielnie
- **4** — potrafię debugować typowe problemy
- **5** — potrafię wyjaśnić innym i podejmować decyzje projektowe

## Zasada oceny
Nie podnoś poziomu tylko dlatego, że „przerobiłeś temat”.
- poziom 2 = rozumienie
- poziom 3 = samodzielne użycie
- poziom 4 = realne debugowanie
- poziom 5 = obrona decyzji i trade-offów
